Cloud Native E-Commerce Platform

User Service Product Service Order Service Notification Service

Automated Cloud-Native Deployment Solution

This project demonstrates Docker containerization, CI/CD automation, Kubernetes deployment, and environment-based DevOps workflows for a fictional e-commerce platform.

User Service

Handles user registration, login, profiles, and authentication.

Product Service

Manages product catalog, inventory, search, and product details.

Order Service

Processes customer orders and tracks order status.

Notification Service

Sends confirmation messages, alerts, and order notifications.

DevOps Final Project | COMSATS University Islamabad, Lahore Campus
